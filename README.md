# Qiti — طوق ذكي بـ GPS للقطط

صفحة هبوط جاهزة للإنتاج لمنتج **Qiti**، طوق ذكي بـ GPS للقطط. كل المحتوى بالدارجة
الجزائرية، RTL كامل، وفيها فورم طلب (كاش عند الاستلام) على طريقة مواقع
التجارة الإلكترونية الجزائرية.

الصفحة ستاتيك بالكامل: **بلا build، بلا framework، بلا أي dependency وقت التشغيل.**
معاها فنكشن وحدة صغيرة (Netlify Function) تبعثلك **إشعار تيليغرام على كل طلب**.

---

## كيفاش تشغّلها

```bash
# الصفحة وحدها (بلا إشعار تيليغرام)
npx serve .
python -m http.server 8000

# الصفحة + الفنكشن (نفس حالة الإنتاج)
npx netlify dev
```

## النشر (Deploy)

الموقع دروك يحتاج **Netlify** على خاطر فيه فنكشن (`netlify/functions/order.mjs`).
GitHub Pages ما يخدمش — يخدم غير ملفات ستاتيك.

```bash
npx netlify deploy --prod
```

ولا اربط الـ repo تاعك (`SWI13/qiti`) من لوحة Netlify، `netlify.toml` يهدر على كلش.

## إشعار تيليغرام على كل طلب

كي زبون يعمّر الفورم ويضغط "أكّد الطلب":

```
                         ┌→ 📱 تيليغرام تاعك — تفاصيل الطلب كاملة
الفورم → /functions/order ┤
                         └→ 💬 SMS للزبون — "طلبك تسجّل" (اختياري)
```

الفنكشن هي اللي تحوز المفاتيح، **ماشي الصفحة**. هذا مهم: الصفحة يشوفها كل
الناس، فلو حطّينا التوكن فيها أي واحد يقدر يسرقو.

### علاش تيليغرام وماشي واتساب؟

جرّبنا واتساب عبر Twilio بلا فايدة. المشكل ماشي في Twilio، المشكل في سياسة
واتساب روحها:

- ما تقدرش تبعث **نص حر** إلا داخل 24 ساعة من آخر رسالة بعثهالك المستقبل.
  برّا هذيك النافذة → خطأ `21654 ContentSid Required`.
- باش تبعث في أي وقت، لازم **template معتمد من Meta**. وكل مرّة تبدّل صيغة
  الرسالة، لازم تعاود تطلب الموافقة.
- حساب Twilio تاع Trial يبعث غير للأرقام المتحقّق منها.

| | واتساب (Twilio) | واتساب (Meta) | **تيليغرام** |
|---|---|---|---|
| الثمن | مدفوع | شبه مجاني | **مجاني بالكامل** |
| موافقة Meta | لازم | لازم | **لا** |
| نص حر في أي وقت | لا | لا | **نعم** |
| وقت الإعداد | ساعات | ساعات | **5 دقايق** |

إذا لازمك واتساب بالضبط (مثلاً الزبائن يعرفوك بيه)، الحل الرسمي هو **Meta
WhatsApp Cloud API** مع template فيه 6 متغيّرات. قوللي ونبدّلوها — الكود
معزول في دالة `notifyOwner()` وحدها.

> ⚠️ **ابعد على** Green API، Whapi، `whatsapp-web.js`، Baileys وأمثالهم.
> يخدمو بربط حساب واتساب تاعك الشخصي، وهذا يخالف شروط واتساب — الحسابات
> تتبلوكي. ما تديرهاش برقم الخدمة تاعك.

### الإعداد — 5 دقايق

**1. دير البوت** — حلّ تيليغرام، لقى [@BotFather](https://t.me/BotFather)،
ابعثلو `/newbot`، اختر اسم. يعطيك توكن شكلو:

```
1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

**2. جيب الـ chat id تاعك** — ابعث [@userinfobot](https://t.me/userinfobot)
أي رسالة، يجاوبك بالـ id تاعك (رقم مثل `987654321`).

**3. ابعث رسالة للبوت تاعك** — مهم! تيليغرام ما يخلّي البوت يبعثلك حتى
تبدا انت المحادثة. حلّ البوت واضغط **Start**.

**4. حطّ الـ environment variables في Netlify** (*Site settings → Environment variables*):

| المتغيّر | الشرح | مثال |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | من @BotFather — **سرّي** | `1234567890:AAHdq…` |
| `TELEGRAM_CHAT_ID` | id تاع الشات ولا الگروب | `-5105623360` |
| `TELEGRAM_WEBHOOK_SECRET` | كلمة سرّ تخترعها انت (للأزرار) | `أي نص عشوائي` |
| `TWILIO_ACCOUNT_SID` | *(اختياري)* لـ SMS الزبون | `ACxxxxxxxx…` |
| `TWILIO_AUTH_TOKEN` | *(اختياري)* — **سرّي** | `xxxxxxxx…` |
| `TWILIO_SMS_FROM` | *(اختياري)* رقم Twilio؛ بلاه ما يتبعثش SMS | `+17372212163` |

للتجريب المحلي، دير ملف `.env` (مضاف في `.gitignore`) بنفس المتغيّرات وشغّل
`npx netlify dev`.

**5. جرّب** — عمّر الفورم وشوف تيليغرام. إذا ما وصلاتش، شوف اللوغ:
*Netlify → Functions → order*. كل طلب يتسجّل في اللوغ حتى لو الإشعار فشل، فما
تخسر حتى زبون.

> **إذا حبيت الإشعار يجي لأكثر من واحد** (شريك، عامل): دير گروب في تيليغرام،
> زيد البوت فيه، واستعمل id تاع الگروب (يبدا بـ `-`) في `TELEGRAM_CHAT_ID`.

### أزرار قبول / رفض الطلب

كل إشعار يجي معاه ثلاث أزرار:

```
🐱 طلب جديد — Qiti

سارة بلقاسم
📞 +213770112233          ← تنقر عليه وتعيّط مباشرة
📍 الجزائر / باب الوادي
🚚 للدار — الكمية ×1

المجموع: 4,500 دج — كاش عند الاستلام

┌─────────────────┬─────────────────┐
│  ✅ قبول الطلب   │  ❌ رفض الطلب   │
├─────────────────┴─────────────────┤
│      💬 راسل الزبون واتساب         │
└───────────────────────────────────┘
```

**كي تنقر قبول** — الرسالة روحها تتبدّل وتزيد سطر أخضر، وأزرار القرار
تختفي (زر واتساب يبقى):

```
✅ مقبول — Abdo · 08/08 01:26
```

**كي تنقر رفض** — البوت يسقسيك على السبب أوّلاً. يردّ على رسالة الطلب
بـ ForceReply (الكيبورد يتحلّ وحدو)، وكي تكتب السبب:

```
❌ مرفوض — Abdo · 08/08 01:31
💬 الزبون ما جاوبش على التيليفون
```

ورسالة السؤال وجوابك يتمسحو، باش الگروب يبقى نظيف — تبقى غير رسالة الطلب
بحالتها النهائية.

> الطلب ما يتقرّرش مرّتين: إذا واحد آخر نقر بعد ما تقرّر، يوصلو تنبيه
> "الطلب راهو مقبول من قبل — Abdo" وما يتبدّل والو.

هكذا الگروب روحو يولّي سجلّ الطلبات: تشوف واش تقبّل، واش تّرفض، علاش،
وشكون دار واش.

> **ملاحظة على "الأخضر"**: تيليغرام ما يخلّيكش تلوّن النص. اللون الوحيد
> اللي نقدرو نستعملوه هو الإيموجي — علاش ✅ (أخضر) و ❌ (أحمر).

**علاش ما كانش زر "اتصل"؟** تيليغرام يرفض روابط `tel:` في الأزرار
(`Wrong port number specified in the URL` — جرّبناها). عوّضناها بحاجة أحسن:
الرقم مكتوب نص عادي بصيغة `+213…`، وتيليغرام يتعرّف عليه أوتوماتيكياً ويديرو
قابل للنقر — تنقر عليه في التيليفون وتعيّط.

#### تشبيك الأزرار — حلّ رابط برك

الأزرار يحتاجو **webhook**: تيليغرام لازم يعرف وين يبعث النقرة. بعد كل
deploy جديد (ولا كي تبدّل `TELEGRAM_WEBHOOK_SECRET`)، حلّ هذا الرابط:

```
https://qitishop.netlify.app/.netlify/functions/telegram-webhook?setup=1
```

الفنكشن تسجّل روحها عند تيليغرام: هي روحها تعرف الـ secret (من الـ env)
وتعرف رابط الموقع، فما تحتاجش تكتب حتى حاجة سرّية بيدك. الجواب يبان هكذا:

```json
{"ok":true,"url":"https://qitishop.netlify.app/.netlify/functions/telegram-webhook","pending":0}
```

**علاش الرابط ثابت وماشي ماخوذ من الطلب**: لو بنيناه من الـ request، أي
واحد يبعث `Host: evil.com` يحوّل الويبهوك لسيرفر تاعو — وتيليغرام يبعثلو
الـ secret في الـ header. علاش ناخذوه من `process.env.URL` (Netlify يحطّو
وحدو)، فحتى لو حلّ الرابط شكون ما كان، ديما يتسجّل نفس الموقع.

الـ secret روحو يمنع النقرات المزوّرة: تيليغرام يزيدو في كل طلب، والفنكشن
ترفض أي حاجة بلاه.

باش تتأكّد وقت ما تحب:

```bash
curl "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"
```

لازم تشوف الـ `url` تاعك و`pending_update_count: 0`. إذا لقيت
`last_error_message`، هذاك هو سبب المشكل.

> **الأزرار ما تخدمش في `netlify dev` المحلي** — تيليغرام يحتاج رابط عمومي
> باش يوصلك. جرّبهم بعد الـ deploy، ولا استعمل `npx ngrok http 8888` إذا
> حبيت تجرّب محلياً.


### تقرير آخر النهار (00:00)

كل ليلة على **00:00 بتوقيت الجزائر** يوصلك تقرير تلقائي في نفس الگروب:

```
📊 تقرير 2026-08-08

📥 الطلبات: 4
✅ مقبولة: 2 (3 طوق)
❌ مرفوضة: 1
⏳ ما زال بلا قرار: 1

💰 مداخيل الطلبات المقبولة: 12,700 دج

أسباب الرفض:
• سارة بلقاسم — الزبون ما جاوبش

طلبات تستنّى قرار:
• كريم — وهران — 4,500 دج
```

سطر "ما زال بلا قرار" يبان غير كي يكونو طلبات ما نقرتش عليهم — يفكّرك
بيهم قبل ما يفوت الوقت.

**التوقيت**: الـ cron تاع Netlify يخدم بـ UTC، والجزائر UTC+1 بلا توقيت
صيفي، علاش الجدول مكتوب `0 23 * * *` (23:00 UTC = 00:00 عندنا) في
`daily-report.mjs`. التقرير يغطّي النهار اللي **كمل**، ماشي اللي بدا.

**⚠️ ما تقدرش تشغّلو بـ curl**: Netlify يمنع استدعاء الفنكشنز المجدولة عبر
HTTP — يرجّع `403` ديما، حتى بالمفتاح الصحيح. (جرّبناها.)

باش تشوفو قبل الوقت، عندك زوج طرق:
- من لوحة Netlify: *Functions → daily-report → Run* (تشغيل يدوي).
- ولا بدّل الجدول مؤقّتاً في `daily-report.mjs` لوقت قريب، مثلاً
  `schedule: '*/5 * * * *'` (كل 5 دقايق)، وكي تتأكّد رجّعو لـ `0 23 * * *`.

### تقرير الأسبوع (كل إثنين 00:00)

كل يوم إثنين على **00:00 بتوقيت الجزائر** يوصلك ملخّص آخر 7 أيام (الإثنين
للأحد اللي فات) في نفس الگروب — نظرة من فوق بعيد على أسبوع كامل بدل يوم
وحدو:

```
📈 تقرير الأسبوع (2026-08-03 → 2026-08-09)

📥 مجموع الطلبات: 23
✅ مقبولة: 15
❌ مرفوضة: 6
⏳ ما زال بلا قرار (أقدم من أسبوع): 2

📦 توصّلت: 12 (14 طوق)
↩️ رجعت: 2

💰 مداخيل فعلية (طلبات توصّلت): 54,600 دج
💵 متوسّط قيمة الطلبية الموصّلة: 4,550 دج
🏆 أكثر ولاية طلبات: الجزائر (7)

طلبات تستنّى قرار من زمان:
• كريم — وهران — 4,500 دج
• سارة بلقاسم — البليدة — 4,900 دج
```

المداخيل تتحسب بنفس منطق تقرير آخر النهار: غير الطلبات اللي **توصّلت**
فعلاً (`deliveryStatus === 'delivered'`)، ماشي كل اللي "مقبولة" (تقدر ترجع
مع المُوصّل). سطر "ما زال بلا قرار" هنا معناه طلبات نسيتها من فوق أسبوع —
إشارة أخطر من نفس السطر في التقرير اليومي.

`store.mjs` ما فيهاش استعلام مدى تواريخ (غير `listOrdersForDay` ليوم
وحدو)، فـ `weekly-report.mjs` يستدعيها 7 مرّات (مرّة لكل يوم من الأسبوع)
ويجمع النتائج.

**التوقيت**: `00:00` يوم الإثنين بتوقيت الجزائر = `23:00 UTC` يوم **الأحد**
اللي قبلو (UTC لسّا ما دخلش الإثنين). علاش الجدول مكتوب `0 23 * * 0` في
`weekly-report.mjs` — الـ `0` الأخير هو الأحد في جدول cron الكلاسيكي
(0=الأحد … 6=السبت)، وماشي `1` (يلي كان يبعث التقرير بيوم كامل متأخّر).

نفس ملاحظة التقرير اليومي: **ما تقدرش تشغّلو بـ curl** مباشرة (Netlify
يرجّع `403` للفنكشنز المجدولة)، جرّبو من *Functions → weekly-report → Run*
في لوحة Netlify، ولا بدّل الجدول مؤقّتاً كيما فوق.

### وين تتخزّن الطلبات

في **Netlify Blobs** — تخزين مدمج في Netlify، بلا قاعدة بيانات وبلا حساب
برّاني وبلا فلوس. هذا علاش زدنا `package.json` (غير باش الفنكشنز تلقى
`@netlify/blobs`؛ الصفحة روحها باقية ستاتيك بلا حتى dependency).

كل طلب يتسجّل **قبل** ما يتبعث الإشعار، يعني حتى لو تيليغرام طاح، الطلب
يبقى محفوظ ويبان في تقرير آخر النهار.

### ⚠️ الأسعار مكتوبة في بلاصتين

الفنكشن **تحسب المجموع بروحها** وما تثقش في اللي يجي من المتصفّح (باش حتى واحد
ما يبدّل السعر بـ DevTools ويبعثلك طلب بـ 1 دج). يعني الثوابت موجودة مرّتين
ولازم يتبدّلو مع بعض:

| البلاصة | الثوابت |
|---|---|
| `assets/js/main.js` | `PRODUCT_PRICE`, `SHIPPING` |
| `netlify/functions/order.mjs` | `PRODUCT_PRICE`, `SHIPPING` |

إذا بدّلتي في وحدة برك، السعر اللي يشوفو الزبون يختلف على اللي يوصلك في تيليغرام.

### التكلفة والربح الصافي — `/cost`

تقرير آخر النهار يحسب "الربح الصافي التقديري" باش تعرف شحال ربحتي فعلاً،
ماشي غير المداخيل. ثلاث تكاليف تدخل في الحساب، وتتبدّل من تيليغرام مباشرة
(بلا `deploy` جديد) بأمر `/cost` — محصور في الشات المسجّل في
`TELEGRAM_CHAT_ID` كيما `/stock`:

```
/cost                  → يعرض التكاليف الثلاثة الحاليّة
/cost product 1600     → سوما البضاعة (لكل طوق)
/cost ads 250          → تكلفة الإعلانات (لكل طلب)
/cost returns 800      → خسارة الرجعة (لكل طلب رجع)
```

القيم الافتراضية (`productCost: 1500، adsCost: 300، returnLoss: 700`) في
`netlify/lib/store.mjs` (`DEFAULT_COSTS`) **تخمين برك** — بدّلهم بـ `/cost`
لأرقامك الحقيقية أوّل حاجة، وإلا رقم "الربح الصافي" في التقرير يبقى غلط.

تكلفة التوصيل (`COURIER_COST` = 350 دج) وحدها ماشي جزء من `/cost` — باقية
ثابتة في `netlify/lib/message.mjs` (تعديلها يحتاج `deploy`). الحساب:
`الربح = المجموع − (سوما البضاعة × الكمية) − تكلفة التوصيل − تكلفة الإعلانات`
للطلبات اللي توصّلت، و`−خسارة الرجعة` للطلبات اللي رجعت.

### حماية من السبام

- **فخّ بوتات** (honeypot): حقل `website` مخبّي في الفورم. البوتات تعمّرو،
  البشر لا. إذا جا معمّر، الفنكشن ترجع نجاح بلا ما تبعث والو.
- **تحقّق من جديد في السيرفر**: الاسم، الهاتف (`0[5-7]XXXXXXXX`)، الولاية،
  البلدية، والكمية (بين 1 و 10) كلهم يتفحصو مرّة ثانية في الفنكشن.

**58 ولاية** مسجّلين في `main.js` (متغيّر `WILAYAS`) ويتعمّرو أوتوماتيكياً في
الـ `<select>`.

## نظام التصميم

كل الـ tokens فوق في `styles.css` تحت `:root`. بدّلهم من هناك وكل الصفحة تتبع
— ما تحتاجش تدخل تبدّل كل rule بوحدها.

```css
--orange-500: #FF6B2C;   /* اللون الأساسي */
--cream:      #FDF8F3;   /* خلفية دافية */
--ink:        #14110F;   /* لون النص — أسود دافي، ماشي #000 خالص */
--r-lg: 24px;            /* سلّم الـ radius: sm/md/lg/xl/full */
--section-y: clamp(72px, 9vw, 132px);
```

**الخط** — `Tajawal` لكلش. مختار خصّيصاً على خاطر عندو وزن 900 حقيقي (أغلب
خطوط العربي ما عندهاش)، وهذا اللي يعطي العناوين الثقيلة شكلها.

**⚠️ مهم إذا بدّلتي لغة الصفحة**: الكتابة العربية سكريبت متّصل — استعمال
`letter-spacing` سلبي (تقنية شائعة في التصميم اللاتيني للعناوين الكبيرة) يهرّس
الحروف المتّصلة. كل الـ headings في هذا الملف مصفّاة من هذا، خلّيها هكاك إذا
زدتي عناوين جداد بالعربي.

**Dark mode** — مجموعة tokens ثانية كاملة تحت `[data-theme="dark"]`. الثيم
يتطبّق بسكريبت صغير في `<head>` *قبل ما ترسم الصفحة*، فما يبانش وميض. التفضيل
يتخزّن في `localStorage`، وإذا المستخدم ما اختارش، تتبع إعدادات النظام.

**RTL** — الصفحة `dir="rtl"` بالكامل. أغلب التخطيط (flex/grid) يتقلب أوتوماتيكياً
مع الاتجاه بلا أي كود إضافي. المواضع المطلقة (الكروت العائمة، الأيقونة داخل
الحقول) تستعمل `inset-inline-start`/`inset-inline-end` (منطقية) بدل
`left`/`right` (فيزيائية) باش تتقلب صحيح. السهم `#i-arrow-rtl` في الـ sprite
مرسوم يشير لليسار مباشرة (اتجاه "القدّام" في RTL) بدل ما نعتمدو على
`transform: scaleX(-1)`.

## ملاحظات الوصول (Accessibility) والأداء

- Skip link، عناصر `<button>`/`<a>` حقيقية، focus rings بايّنة.
- FAQ تستعمل `<details>`/`<summary>` — تخدم حتى بلا جافاسكريبت.
- بلا جافاسكريبت، الصفحة تبقى مقروءة كاملة؛ غير الأنيميشن، الثيم، وفورم الطلب
  اللي ما يخدموش (الفورم HTML يبقى بايّن بصح ما يقدرش يتحقّق أو يبعث).
- `prefers-reduced-motion` محترم بالكامل.
- `will-change` يتحطّ غير وقت الأنيميشن الفعلي، باش الصفحة ما تبقاش شادّة
  compositor layers بزاف بعد التحميل.
- صورة الـ hero بـ `fetchpriority="high"`؛ كل الصور تحت الطيّة `loading="lazy"`.
- الأيقونات كلهم SVG sprite واحد — بلا أي مكتبة أيقونات جافاسكريبت.

## بخصوص Tailwind

الطلب الأصلي ذكر Tailwind. هذا المشروع مبني بـ **CSS مكتوب يدوياً بنظام tokens**
عوض هذا، قصداً:

- Tailwind Play CDN يترجم في المتصفح وقت التشغيل — يزيد ~300KB جافاسكريبت
  ويعمل flash of unstyled content. ماشي معمول للإنتاج، وطلبتي صفحة سريعة بزاف.
- Tailwind build حقيقي يحتاج npm، config، وخطوة build لصفحة ستاتيك وحدة.

النتيجة: ملف CSS واحد ~35KB، بلا dependencies، بلا build. إذا تحب Tailwind +
Vite حقيقي، أسماء الـ tokens تتحول مباشرة لـ `theme.extend` — قوللي ونديرها.
